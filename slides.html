追问 1–2 / 5

核心机制 · 怎么学、怎么传

784 个像素，谁该打高分、谁该打低分？

训练找参数组合，梯度下降微调权重，正确分数越来越高。

20 万参数，每个都要单独算影响吗？

反向传播多米诺倒推 = 分锅：这层传入什么 × 上层传来什么误差。链式法则把 21.8 万参数逐个试，从 O(N²) 降到一次算完。

追问 3–4 / 5

关键设计 · 怎么激活、怎么初始化

线性层叠加会「合并」，如何打破？

ReLUmax(0, x)，正数放行、负数清零。Sigmoid 两端导数趋 0，梯度传着传着就消失；ReLU 正区斜率恒 1，代价是 10–20% 神经元死亡。

ReLU 砍掉负数，神经元会废掉吗？

He 初始化精确补偿。全零会退化成一个神经元，随机可能全员落负区死亡；He 用方差 2/fan_in 补偿砍掉的一半，点亮约一半神经元。

3a = np.maximum(0, z)  # 正数放行、负数清零
4# 反向: ReLU 导数 = z > 0
5da = da * (z > 0)

追问 5 / 5

关键设计 · 怎么衡量、怎么优化

怎么衡量「猜得好不好」，误差信号从哪来？

交叉熵 CE梯度 = 预测 − 答案，错得越离谱信号越强。MSE 有隐藏坑：错得越狠，梯度被 P(1−P) 压得越弱。

步长怎么定，怎么不来回震荡？

Adam 针对 SGD 三坑——峡谷震荡 / 尺度不均 / 鞍点停滞，用动量记方向 + 自适应步长 + 偏置校正一一化解。

mnist_nn.py · loss [4]
1# 交叉熵: L = -log(P_correct)
2loss = -np.mean(np.log(probs[arange(N), y] + 1e-12))
3# CE+Softmax 合体梯度 = (P - y)/N
4d = probs.copy(); d[arange(N), y] -= 1; d /= N
mnist_nn.py · Adam [5]
1m = b1*m + (1-b1)*g    # 动量 → 消震荡
2v = b2*v + (1-b2)*g**2   # RMSprop → 自适应步长
3mh = m/(1-b1**t); vh = v/(1-b2**t)  # 偏置校正
4w -= lr * mh / (np.sqrt(vh) + eps)
架构与训练

784 → ReLU(256) → ReLU(64) → Softmax(11)

256 → 64 逐层递减 = 信息瓶颈：太窄挤掉信息，太宽直接背答案。
